# Программа кодирования и декодирования по методу Хаффмана

Программа реализует кодирование и декодирование файлов по методу Хаффмана. Обработка выполняется побайтово, поэтому программа подходит как для текстовых, так и для бинарных файлов.

## Состав проекта

```text
src      - исходный код программы на Java
input    - исходные файлы для контрольной проверки
encoded  - каталог для закодированных файлов
decoded  - каталог для файлов, восстановленных после декодирования
docs     - описание структуры закодированного файла
out      - каталог для class-файлов после компиляции
```

Основные файлы исходного кода:

```text
Main.java             - обработка аргументов командной строки
HuffmanArchiver.java  - кодирование, декодирование и работа с форматом HUF1
HuffmanNode.java      - узел дерева Хаффмана
BitOutputStream.java  - побитовая запись данных
BitInputStream.java   - побитовое чтение данных
```

## Сборка

Для сборки проекта используется JDK. Сборка выполняется командой:

```bat
build.bat
```

После успешной сборки создаются:

```text
out\*.class
huffman.jar
```

Ручная команда компиляции:

```bat
javac -encoding UTF-8 -d out src\*.java
```

## Запуск программы

Общий формат запуска:

```bat
java -jar huffman.jar encode <исходный_файл> <закодированный_файл>
java -jar huffman.jar decode <закодированный_файл> <восстановленный_файл>
```

Также можно запускать программу без jar-файла:

```bat
java -cp out Main encode <исходный_файл> <закодированный_файл>
java -cp out Main decode <закодированный_файл> <восстановленный_файл>
```

Для удобства добавлены командные файлы:

```bat
encode.bat input\test1.txt encoded\test1.huff
decode.bat encoded\test1.huff decoded\test1_decoded.txt
```

## Контрольная проверка

В каталоге `input` подготовлены файлы:

```text
test1.txt - файл из 10 одинаковых символов
test2.txt - файл длиной 20 байт из трех разных символов с частотами 10, 5 и 5
```

После компиляции программы в качестве бинарного файла для проверки используется:

```text
out\Main.class
```

Запуск всех проверок:

```bat
run_tests.bat
```

Скрипт выполняет кодирование, декодирование и побайтовое сравнение исходных и восстановленных файлов.
